# Survival Game Prototype

An Unreal Engine 5 survival game prototype focused on resource gathering, crafting, and player-built structures.

## Features

### Resource Gathering

Implemented systems that allow the player to gather resources from different environmental objects, including:

* Trees
* Rocks
* Bushes

Gathered resources are used as materials for crafting and construction.

### Crafting System

Developed a crafting system that allows collected resources to be converted into different building pieces.

### Building System

Implemented a building-placement system that allows the player to:

* Select crafted building pieces.
* Position pieces within the game world.
* Place structures directly into the environment.

## Technologies

* Unreal Engine 5
* C++
* Blueprints
* Resource Systems
* Crafting Systems
* Building Placement
* Player Interaction
* Collision Detection
